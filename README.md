🚀 Online Learning & Course Recommendation Platform (LMS)

A full-stack MERN-based Learning Management System that allows users to register, login, browse courses, and enroll in courses securely using JWT authentication.

🔥 Live Demo
Backend: https://full-stack-development-online-learning.onrender.com  

✨ Features
- User Registration & Login (JWT Authentication)
- Course Listing System
- Course Enrollment System
- Basic Course Recommendation Logic
- MongoDB Atlas Database Integration
- Protected Routes using Middleware
- Fully Deployed Backend (Render)
- Responsive React Frontend UI

🛠️ Tech Stack
Frontend: React.js, JavaScript, CSS  
Backend: Node.js, Express.js  
Database: MongoDB Atlas  
Auth: JWT (JSON Web Token)

## ⚙️ Setup Instructions
git clone https://github.com/Aarthikole18/Full-stack-Development-Online-Learning-and-Course-Recommendation-Platform.git  
cd server  
npm install  
npm run dev  

cd client  
npm install  
npm run dev  

## 🔐 Environment Variables
PORT=5000  
MONGO_URI=your_mongodb_connection_string  
JWT_SECRET=your_secret_key  

## 🚀 API Endpoints
Auth: /api/auth/register, /api/auth/login  
Courses: /api/courses  
Enrollments: /api/enrollments
